# Panduan Penggunaan Aplikasi KasKu

Aplikasi **KasKu** adalah aplikasi pencatat keuangan pribadi / kas keluar masuk yang dirancang dengan antarmuka elegan, modern, dan mudah digunakan (mobile-friendly).

## Fitur Utama
1. **Pencatatan Arus Kas**: Catat transaksi uang masuk (pemasukan) dan uang keluar (pengeluaran) lengkap dengan nominal, kategori, dan keterangan.
2. **Ringkasan Saldo Otomatis**: Memantau total saldo, total pemasukan, dan total pengeluaran secara real-time.
3. **Penyimpanan Lokal (LocalStorage)**: Data transaksi Anda tersimpan aman di browser sehingga tidak akan hilang saat halaman dimuat ulang.
4. **Filter Transaksi**: Saring riwayat transaksi berdasarkan jenis (Semua, Uang Masuk, atau Uang Keluar).
5. **Ekspor ke Excel**: Unduh laporan keuangan lengkap dalam format `.xlsx` dengan satu klik tombol.

## Cara Menjalankan Aplikasi
1. Buka file [`index.html`](index.html:1) langsung menggunakan browser web (Chrome, Edge, Firefox, Safari).
2. Mulai tambahkan catatan keuangan Anda!
